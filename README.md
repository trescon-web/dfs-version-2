## ✨ Features & Architecture

- 🚀 **High-Performance Next.js 16 App Router**: 100% static prerendered routes for lightning-fast page loads.
- 🎨 **Luxury Modern Aesthetic**: Dark mode video backgrounds, backdrop glassmorphism, dynamic typography, and custom cyan accents (`#12E9E9`).
- 📱 **100% Mobile Responsive**: Touch-swipeable press carousels, responsive navigation menus, dynamic patron banners, and adaptive grid layouts.
- 🎙️ **Interactive Features**: Filterable Agenda Planner, Speaker Directory, Sponsor Ecosystem, Interactive Event Map, and Live Search Modal (`Ctrl + K`).
- ⚡ **Optimized Assets**: Next.js Image optimization, fluid vector graphics, and smooth Framer Motion micro-interactions.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/trescon-web/dubai-fintech-summit-v2.git
cd dubai-fintech-summit-v2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application live.

### 4. Build for production
```bash
npm run build
npm run start
```
